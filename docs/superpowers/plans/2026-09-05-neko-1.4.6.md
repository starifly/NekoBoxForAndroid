# NekoBox 1.4.6 Implementation Plan

**Goal:** Repair confirmed compatibility, lifecycle, Router and UI defects and ship a verified 1.4.6 build.

**Architecture:** Preserve the Room Router model and sing-box integration. Fix each defect at its owner; retain the 300-second URL_TEST interval and event-driven foreground refresh.

**Tech Stack:** Kotlin, Android API 21–35, Room, Go/libcore, Gradle.

**Spec:** User request to review, optimize and repair the project for 1.4.6, with prior authorization to push GitHub.

## Constraints

- Preserve existing routing, AdBlock, subscriptions and configuration files; do not inspect A7/isA8.
- Keep runtime failures distinct from dependency update and style advisories. Do not broadly suppress real lint defects.
- Device behavior and battery measurements require a connected phone; a build cannot prove them.
